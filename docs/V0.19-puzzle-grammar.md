# V0.19 — Compositional Puzzle Grammar

## Purpose

Replace terrain-only random mutation as the primary Generate Puzzle path with an explicit grammar of mechanics. A candidate is accepted only when the production game solver can solve it and the advertised core mechanics pass ablation checks.

## Productions

| Production | Composition | Required control |
|---|---|---|
| phase-gate | Full-height phase barrier + solid-only exit | Matter toggle (p) |
| frozen-gate | Phase barrier + rule frozen => phase open | Time freeze (f) and its conditional law |
| gravity-shaft | Vertical solid barrier with a top passage | Global gravity (g) |
| ghost-reversal | Vertical solid barrier + rule ghost => reverse gravity + solid-only exit | Matter toggle (p) and its conditional law |
| switch-phase | Pushable box + pressure plate + door + freeze bypass + phase barrier | Time freeze (f), matter (p), box, and plate |

## Generation and acceptance

1. Select a grammar production.
2. Instantiate a parameterized 10×6 map.
3. Search the state graph using the same initial, step, solve, and won functions as the game.
4. Reject unsolvable or malformed candidates.
5. Ablate each permitted control independently; every declared control must be necessary.
6. Ablate every conditional law; every declared law must be necessary.
7. For switch-phase, remove the box and pressure plate separately; either ablation must make the puzzle unsolvable.
8. Replay the shortest solution and verify that it reaches the goal.
9. Deduplicate candidates and select uniformly among grammar families that produced valid candidates.

The adaptive-training recommender filters by the weakest rule and prefers a single-required-rule puzzle before choosing by path length and state count. This keeps focused practice from unnecessarily introducing a second mechanic.

## Validation

Run locally:

```sh
node tests/puzzle-grammar.test.cjs
```

The regression test checks 256 parameter seeds per grammar family, shortest-path replay, control/law/box/plate ablations, 500 generator seeds, family balance, map diversity, and focused recommendations.

Latest recorded run:

- 5 grammar families.
- 256/256 parameter seeds accepted for each family.
- 500/500 generator seeds produced a valid puzzle.
- Family selection was approximately balanced.
- 174 distinct family/map combinations appeared across the 500-seed sample.
- Mean valid unique candidates per 64-attempt search: 57.04.
- Focused recommendations correctly isolated gravity, matter, and time.

These are software/structural validation results, not human playtest or cognitive-difficulty measurements.

## Known limitations

- The grammar is deliberately small and targets the existing 10×6 board.
- Several productions share a similar corridor structure.
- Shortest-path count and reachable-state count are structural descriptors, not validated estimates of perceived difficulty.
- Human playtests are still required to calibrate pacing, clarity, frustration, and actual difficulty.
- Legacy terrain-evolution functions remain in the source as an experimental fallback, but the primary generation button now calls the grammar generator.
